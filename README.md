# PUBG Analytics System 🎯
Dự án chương trình đầu tay được xây dựng dựa trên tựa game PUBG bằng ngôn ngữ C/C++

#Giới thiệu về dự án#
Đây là chương trình Console giúp người chơi theo dõi lịch sử thi đấu, dọn dẹp dữ liệu lỗi, sắp xếp thứ hạng và đưa ra các thống kê quan trọng về phong độ thi đấu.

#Tại sao tôi chuyển sang sử dụng đuôi tệp `.cpp`?
Dù logic chính của chương trình vẫn dựa trên nền tảng ngôn ngữ C, tôi sử dụng phần mở rộng `.cpp` thay vì `.c` vì:
--> vì hỗ trợ Tham chiếu (Reference `&`)
--> vì khả năng mở rộng

#Các tính năng chính của chương trình: 
Module 1 - Analyze: Phân tích chỉ số kill, tính tổng, điểm cá nhân, tính trung bình và cảnh báo phong độ 0-kill.
Module 2 - Clean Data: Tự động phát hiện và xóa/chỉnh sửa các trận đấu có số kill vô lý (<0 hoặc >100)
Module 3 - Rank: Sắp xếp trận đấu và phân loại thứ hạng (S, A, B) dựa trên số kill.
Module 4 - Strategy: Đảo ngược danh sách để ưu tiên xem trận mới nhất và tìm kiếm trận đấu theo yêu cầu.

# PUBG Analytics System 🎯
The first program project is built based on the PUBG game in C/C++ language

#Introduction to the project#
This is a Console program that helps players track competition history, clean up error data, sort rankings and provide important statistics on competition performance.

#Why did I switch to using the file extension `.cpp`?
Although the main logic of the program is still based on the C language, I use the `.cpp` extension instead of `.c` because:
--> because it supports Reference (Reference `&`)
--> because of scalability

#Main features of the program:
Module 1 - Analyze: Analyze kill index, calculate total, individual score, average and warn of 0-kill performance.
Module 2 - Clean Data: Automatically detect and delete/edit matches with unreasonable kills (<0 or >100)
Module 3 - Rank: Arrange matches and classify rankings (S, A, B) based on number of kills.
Module 4 - Strategy: Reverse the list to prioritize viewing the latest matches and search for matches on demand.
